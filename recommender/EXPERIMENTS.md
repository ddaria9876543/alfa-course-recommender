# Эксперименты с рекомендательными алгоритмами

## 1. Цель

Выбрать алгоритм персональных рекомендаций образовательных материалов платформы «Альфа-Курс» на основе бизнес-целей предпринимателей.

## 2. Данные

Источник — PostgreSQL, аналитическая витрина `analytics.dm_materials`.

В каталоге содержится 1 075 доступных для рекомендаций материалов: статьи, курсы и документы.

Для оценки использованы три тестовых профиля:

- `beauty_sales` — увеличение продаж и привлечение клиентов салона красоты.
- `business_start` — регистрация ИП и запуск бизнеса.
- `online_store` — открытие интернет-магазина.

Для оценки релевантности вручную размечены 53 пары «профиль — материал».

Шкала релевантности:

- `0` — материал не соответствует задаче.
- `1` — материал частично полезен.
- `2` — материал непосредственно соответствует задаче.

## 3. Сравниваемые алгоритмы

1. **Baseline** — базовый алгоритм рекомендаций.
2. **TF-IDF** — ранжирование по текстовому сходству.
3. **Personalized TF-IDF** — TF-IDF с учётом пользовательского профиля.
4. **Hybrid** — экспериментальное сочетание текстового сходства и метаданных.
5. **Semantic Search** — семантическое ранжирование с использованием `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`.

## 4. Метрики

Использовались:

- **Precision@5** — доля релевантных материалов среди первых пяти рекомендаций.
- **Recall@5** — доля найденных релевантных материалов относительно размеченного пула кандидатов.
- **NDCG@5** — качество порядка рекомендаций с учётом градаций релевантности.

Для Precision@5 и Recall@5 релевантными считались материалы с оценками `1` и `2`.

## 5. Результаты

| Алгоритм | Precision@5 | Recall@5 | NDCG@5 |
|---|---:|---:|---:|
| Baseline | 0.5333 | 0.2063 | 0.3165 |
| TF-IDF | 0.8667 | 0.4008 | 0.7299 |
| **Personalized TF-IDF** | **0.8667** | **0.4008** | **0.7323** |
| Hybrid | 0.6000 | 0.2778 | 0.3958 |
| Semantic Search | 0.6667 | 0.3175 | 0.4660 |

Показаны средние значения по трём тестовым профилям.

## 6. Анализ

Лучший NDCG@5 на текущем тестовом наборе показал Personalized TF-IDF — 0.7323.

Экспериментальный гибридный алгоритм уступил TF-IDF. Повышенное влияние метаданных приводило к появлению рекомендаций, соответствующих широкой тематике, но не конкретной бизнес-задаче.

Семантический поиск помогал находить смысловые соответствия, однако иногда предлагал материалы из смежных, но нерелевантных областей бизнеса.

Разница между TF-IDF и Personalized TF-IDF невелика. Для подтверждения преимуществ персонализации необходимо расширить тестовую выборку.

## 7. Выбранное решение

Для MVP выбран **Personalized TF-IDF**.

Причины выбора:

- Наибольший NDCG@5 на текущем тестовом наборе.
- Возможность использовать бизнес-цель и параметры пользовательского профиля.
- Отсутствие необходимости запускать нейросетевую модель при формировании рекомендаций.
- Более простое развёртывание и интеграция с backend.

## 8. Ограничения оценки

Эксперимент охватывает только три пользовательских профиля и 53 вручную размеченные пары.

Материалы отбирались из выдач сравниваемых алгоритмов. Поэтому выборка не является случайной и не охватывает все релевантные материалы каталога.

Результаты характеризуют качество ранжирования на текущем размеченном наборе и не гарантируют аналогичных показателей для всех пользователей платформы.

Для более объективной оценки необходимо расширить число тестовых профилей, разметить дополнительные материалы и провести проверку на новых сценариях.

## 9. Воспроизведение

Основные зависимости:

```powershell
python -m pip install -r requirements.txt
```

Дополнительные зависимости для семантических экспериментов:

```powershell
python -m pip install -r requirements-experiments.txt
```

Проверка рабочего рекомендательного сервиса:

```powershell
python -m unittest recommender.test_service -v
```

Сравнение алгоритмов:

```powershell
python -m recommender.compare_all_models
```

Для воспроизведения последнего сравнения необходимы локальные CSV-файлы с ручной разметкой и ранжированием алгоритмов в `recommender/reports/`. Они не включены в публичный репозиторий.

Итоговые метрики зафиксированы в настоящем документе.
